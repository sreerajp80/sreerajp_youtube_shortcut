# Plan: Bulk QR Code Export & Import (All Shortcuts & Settings)

**Status:** Proposed (Awaiting User Approval)

## Issue
Currently, QR code sharing only supports encoding and scanning a **single** YouTube shortcut at a time. While file-based JSON backup/restore exists under Backup & Restore, users cannot transfer their entire collection of shortcuts and app settings across air-gapped devices directly using camera scanning.

## Goal
Implement **Bulk QR Code & Animated QR Code Handoff** for all YouTube shortcuts and app settings in `YT Shortcuts`:
1. **Bulk QR Generator Dialog / Screen:** Export all shortcuts and settings into a QR code payload.
   - If the JSON fits in a single QR code, display a static QR code.
   - If the JSON payload exceeds single QR capacity, split into chunk payloads and cycle them as an **Animated QR Code** stream (AirQR frame loop).
2. **QR Scanner Stream Collector:** Update `QrScannerScreen` and `QrPayloadParser` to recognize `yt_shortcuts_backup` and `yt_shortcuts_chunk` payloads, assemble stream chunks into full JSON, and display a "Full Backup Received" handoff dialog with options to merge or replace shortcuts and settings.
3. **Backup & Restore Integration:** Add a "Share via QR Code" action button in `BackupRestoreScreen` and a "Scan Backup QR" option.

## Files to Change
- `lib/src/qr_payload_parser.dart`: Add parsing and encoding methods for bulk backup JSON payloads and chunked payload streams.
- `lib/src/widgets/bulk_qr_dialog.dart` (NEW): Widget to render static or animated multi-frame QR codes for full backup data.
- `lib/src/screens/qr_scanner_screen.dart`: Handle chunk accumulation, progress indicator for animated QR scanning, and full backup restore sheet.
- `lib/src/screens/backup_restore_screen.dart`: Add "Export via QR Code" button and "Scan Backup QR" trigger.

### Manual Verification
