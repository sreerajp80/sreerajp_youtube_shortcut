# Set App Name to "SreerajP YouTube Shortcuts"

**Status:** completed

## Issue

The app name is not the same everywhere. Right now:

| Place | Current value |
|-------|---------------|
| `assets/config/app_config.json` (About screen) | SreerajP YouTube Shortcuts |
| `lib/core/config/app_config.dart` (fallback) | SreerajP YouTube Shortcuts |
| `android/app/build.gradle.kts` (launcher label) | YT Shortcuts / YT Shortcuts Dev |
| `lib/src/screens/home_screen.dart` (app bar title) | YT Shortcuts |
| Lock screen, biometric prompt, backup errors, QR dialogs | YT Shortcuts |
| `README.md`, `CLAUDE.md`, `AGENTS.md`, `docs/*` | YT Shortcuts |

The user wants the full name "SreerajP YouTube Shortcuts" used everywhere: the
Android launcher label, the home screen app bar title, all in-app text, and the docs.

## Note for the user (please read before approving)

"SreerajP YouTube Shortcuts" is 27 characters. Android launchers usually show only
about 10-12 characters under an icon, so the label on the phone home screen will be
cut short (for example "SreerajP YouT..."). This is only a display limit, not a bug.
If you prefer a short launcher label, say so and this plan will be changed.

The app bar title is also long. It will be shortened with "..." on small screens.
The plan keeps the full name as asked and lets Flutter handle the overflow.

## Out of scope (will not change)

- `assets/config/app_config.json` and `lib/core/config/app_config.dart` — already
  hold the correct full name.
- Package / application ID (`in.sreerajp.sreerajp_youtube_shortcut`) — unchanged.
  Changing it would break existing installs and signing.
- `pubspec.yaml` `name:` field — this is the Dart package name, not a display name.
- `docs/guidelines/` (a submodule) and `docs/flutter_*` guideline docs — these use
  "MyApp" as a generic example, not this app's name.
- `plans/` and `change_log/` history files — old records stay as written.
- `docs/potential_features.md` — a roadmap doc; it may keep the short form.

## Plan for the fix

1. Change the two Gradle `resValue` lines so the launcher label uses the full name.
2. Change every user-visible Dart string listed above to the full name.
3. Update the docs and tables listed above.
4. Verify:
   - `dart format --output=none --set-exit-if-changed .`
   - `flutter analyze` (must be clean)
   - `flutter test` (must be zero failures)
   No tests currently assert on the string "YT Shortcuts", so no test updates are
   expected. If a golden or widget test breaks, it will be fixed in place.
5. Write the change log to `change_log/` referencing this plan.

## Risk

Low. These are display strings only. No storage keys, no backup format fields, and
no package IDs change, so existing shortcuts and existing backup files keep working.
