## 2. Goals And Non-Goals

### Goals

- Let the user create a named shortcut entry from a YouTube URL and a custom shortcut name.
- Normalize supported YouTube URLs into a canonical launch target that can be handed directly to
  the YouTube Android app.
- Store all shortcut entries locally on-device and keep them available after app restart.
- Render shortcuts on the home screen where tapping an item opens the installed YouTube app.
- Provide privacy protection: optional App Lock and Private Vault with PIN and biometric authentication.
- Support offline backups: plain JSON, encrypted AES-256 JSON, and animated chunked QR code sequence.
- Provide an About screen that dynamically renders metadata from `assets/config/app_config.json`.
- Keep the Flutter app itself fully offline with no app-managed HTTP traffic and no `INTERNET` permission.

### Non-Goals

- Streaming, downloading, or controlling playback inside this app.
- Google account sign-in, YouTube API integration, sync, or cloud storage.
- Home-screen launcher pinned shortcuts, widgets, or notification shortcuts in v1.
- Browser fallback when the YouTube app is missing; v1 shows a clear local error instead.
- Support for platforms other than Android.

## 3. Architecture Summary

The app is a small Android-only Flutter 3.44.8 application using a Tier 1 layer-first structure.
The user enters a shortcut name and a YouTube URL on the Add Shortcut screen (or shares a link via
Android's SEND intent). A formatter service validates the host and path, normalizes supported YouTube links
into a canonical HTTPS YouTube URI, and produces an immutable `ShortcutEntry`. Entries are persisted locally
as JSON in `SharedPreferences`. The home screen renders the saved shortcuts as tappable cards or a grid.
Tapping a shortcut delegates to an Android launcher service that sends an explicit intent to the YouTube
package (`com.google.android.youtube`) so the target opens directly in the YouTube app. The app contains no
network client and never requests `INTERNET`.

## 5. App Initialization Sequence

| Step | Code / Call | Notes |
|------|-------------|-------|
| 1 | `WidgetsFlutterBinding.ensureInitialized()` | Always first |
| 2 | Configure `FlutterError.onError` and `PlatformDispatcher.instance.onError` | Required by engineering standard before UI startup |
| 3 | `final prefs = await SharedPreferences.getInstance()` | Initializes local shortcut storage |
| 4 | `final packageInfo = await PackageInfo.fromPlatform()` | Supplies version and build number |
| 5 | Resolve build metadata and `AppConfig` via `ConfigService` | Verifies `assets/config/app_config.json` against `packageInfo` |
| 6 | Construct repository, services, and root state stores (`ShortcutStore`, `PrivacyLockStore`) | Manual dependency wiring |
| 7 | Load stores (`store.load()`, `privacyLockStore.load()`) | Loads shortcuts and lock state from storage |
| 8 | `runApp(ShortcutApp(...))` | Launches the app with providers attached |

## 7. Offline Behavior

- **Connectivity requirement**: `fully offline`
- **Network permission**: `INTERNET permission absent`
- **Offline data source**: `SharedPreferences` JSON payload

---

## 8. State Management

- Primary pattern: `ChangeNotifier` with `provider`
- State holders:
  - `ShortcutStore`: shortcuts collection, active filters, search query, sorting, theme preference, selection mode, bulk actions.
  - `PrivacyLockStore`: PIN configuration, lock status (app-level and private vault), biometric settings, lifecycle observer.

---

## 9. Data Flow

```text
AddShortcutScreen
  -> YoutubeUrlFormatter
  -> ShortcutStore.addShortcut()
  -> ShortcutRepository.saveShortcuts()
  -> SharedPreferences

HomeScreen tap
  -> YoutubeLauncherService.launch()
  -> Android Intent to com.google.android.youtube
```

## 10. Error Handling Architecture

- Global error handlers in `main()` catch unhandled Flutter and platform errors.
- Domain exceptions inherit from sealed `AppException` in `lib/core/errors/app_exception.dart`:
  - `ShortcutValidationException`
  - `ShortcutStorageException`
  - `ShortcutBackupException`
  - `YoutubeLaunchException`
- Error codes map to localized UI strings via `lib/l10n/error_messages.dart`.

---

## 11. Domain Model

- Models in `lib/models/`:
  - `ShortcutEntry`: immutable entity representing a shortcut.
  - Enums: `ShortcutTargetType`, `ShortcutSortPreference`, `AppLayoutPreference`, `AppThemePreference`.
  - `QrPayloadParser`: serializes/deserializes single shortcuts and multi-part backup payloads.

---

## 12. Dependency Management And Injection

- DI approach: manual dependency wiring with `MultiProvider` in `app_shell.dart`.
- Services and stores injected via constructors.

---

## 13. Navigation

- `Navigator 1.0` with `MaterialPageRoute`.
- Navigation flow starts from `HomeScreen` wrapped in the `PrivacyLockScreen` gate.

---

## 14. Persistence And External Systems

- `SharedPreferences`: stores JSON shortcuts and settings.
- Android platform channels:
  - `build_metadata`: retrieves Gradle build time and version code.
  - `share_intent`: receives external shared text/links.
  - `backup_io`: interacts with Storage Access Framework for JSON files.

## 15. Environment And Build Model

- Flavors: `dev` and `prod`.
- Release signing: `android/key.properties` pointing to `android/keystore.jks`.
- Production builds require `--release`, `--obfuscate`, and `--split-debug-info`.

## 16. UI System

- All user-visible strings localized in `lib/l10n/app_en.arb`.
