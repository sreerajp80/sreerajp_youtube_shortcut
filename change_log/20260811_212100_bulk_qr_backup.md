# Change Log: Bulk QR Code & Animated QR Transfer for All Shortcuts & Settings

**Plan:** [20260811_212100_bulk_qr_backup.md](file:///l:/Android/sreerajp_youtube_shortcut/plans/20260811_212100_bulk_qr_backup.md)

## Summary of Changes
1. **Bulk & Animated QR Payload Parser:**
   - Updated `QrPayloadParser` to encode and parse `yt_shortcuts_backup` (full backup payloads) and `yt_shortcuts_chunk` (animated QR stream frames).
   - Created `createChunkFrames` helper to split large JSON backup payloads into 500-character chunk frames for animated QR transmission.

2. **Bulk QR Code Generation Dialog (`BulkQrDialog`):**
   - Created `BulkQrDialog` modal widget to encode all shortcuts and app settings (theme, layout, sort, favorites-first) into static or animated QR code streams.
   - Added **Estimated Transfer Time** calculation based on frame count and frame display speed.
   - Added **Huge Data Warning Banner** when frame count exceeds 15 frames or shortcuts count exceeds 50, advising users to use file export for very large datasets.
   - Added Play/Pause stream controls for animated QR code cycling.

3. **QR Scanner Stream Collector (`QrScannerScreen`):**
   - Enhanced camera QR scanner to detect `backupChunk` frames and track progress (`Frame X/Y received`).
   - Reassembled animated QR frames into full JSON backup payloads once all frames are collected.
   - Added "Full Backup Received!" receiver handoff sheet with options to **Merge with Existing Shortcuts** or **Replace All Shortcuts**, applying both shortcuts and app settings preferences.

4. **Backup & Restore Integration (`BackupRestoreScreen`):**
   - Added **Export via QR code** action button under Export section.
   - Added **Scan Backup QR** action button under Import section.

5. **Unit Testing:**
   - Added unit tests in `test/qr_payload_parser_test.dart` for full backup encoding/parsing and animated QR frame reassembly.
