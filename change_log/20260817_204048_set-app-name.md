# Change Log — Set App Name to "SreerajP YouTube Shortcuts"

Implements plan: `plans/20260817_203536_set-app-name.md`

## Summary

The app used two names: the full "SreerajP YouTube Shortcuts" on the About screen, and
the short "YT Shortcuts" in the Android launcher label, the home screen app bar, and
several in-app messages. Every visible place now uses the one full name.

## Changes

### Android launcher label

- `android/app/build.gradle.kts`
  - `dev` flavor `app_name`: "YT Shortcuts Dev" → "SreerajP YouTube Shortcuts Dev"
  - `prod` flavor `app_name`: "YT Shortcuts" → "SreerajP YouTube Shortcuts"

### Visible titles and in-app text

- `lib/src/screens/home_screen.dart` — app bar title is now
  "SreerajP YouTube Shortcuts".
- `lib/src/screens/privacy_lock_screen.dart` — default `title` is now
  "SreerajP YouTube Shortcuts Locked".
- `lib/src/app_shell.dart` — the title passed to `PrivacyLockScreen` matches the new
  locked title.
- `lib/src/privacy_lock_store.dart` — biometric prompt reason is now
  "Unlock SreerajP YouTube Shortcuts".
- `lib/src/services/privacy_lock_service.dart` — default biometric reason is now
  "Authenticate to access SreerajP YouTube Shortcuts".
- `lib/src/backup_service.dart` — both "not a ... backup" error messages now name the
  app in full (2 places).
- `lib/src/screens/qr_scanner_screen.dart` — restore description text and the
  "Save to SreerajP YouTube Shortcuts" button label.
- `lib/src/widgets/bulk_qr_dialog.dart` — the "Scan this QR code with ..." helper text.

### Docs

- `CLAUDE.md` and `AGENTS.md` — the App name row now says the name is used everywhere
  with no short form; both build-flavor tables show the new display names.
- `README.md` — build-flavor table display names.
- `docs/architecture.md` — replaced the "suggested short display names" list with the
  single display name; updated the build-flavor table.
- `docs/features.md` — document title and intro, build-flavor display names, the app
  bar title description, and the "Note on app name" block, which now explains there is
  one name and that long names are visually truncated by the launcher and by narrow
  app bars.

### Not changed

- `assets/config/app_config.json` and `lib/core/config/app_config.dart` already held the
  correct full name.
- Application ID, `pubspec.yaml` package name, storage keys, and backup payload fields
  are untouched, so existing installs, saved shortcuts, and old backup files keep
  working.
- `docs/guidelines/` and the `docs/flutter_*` guideline documents use "MyApp" as a
  generic example, so they were left alone.

## Verification

- `flutter analyze` — clean, no issues found.
- `flutter test` — all 72 tests pass. No test asserted on the old "YT Shortcuts"
  string, so no test needed updating.
- `dart format --output=none --set-exit-if-changed .` — still reports the same
  pre-existing failures. This was checked against a clean tree before these edits and
  the same 17 files already failed, including files this change never touched. The
  repository code is written in the older Dart formatter style while the installed Dart
  SDK uses the newer style. Each line added by this change was compared against the
  formatter's preferred output and none of them are flagged. Reformatting the whole
  repository was left out of scope because it would rewrite many unrelated files.

## Note for the user

"SreerajP YouTube Shortcuts" is 27 characters. Android launchers usually show only
about 10-12 characters under an icon, so the phone home screen label will appear cut
short. The home screen app bar will also shorten it with "..." on small screens. This
is a display limit of those surfaces, not a bug.
